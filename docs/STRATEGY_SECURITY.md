# 策略模块安全边界

策略库保存的是研究代码快照，不负责执行 Python 代码。当前实现把策略代码作为不可信输入处理，并在保存版本时完成基础结构和静态风险校验。

## 当前保护

- 策略、版本和关联标的的写操作只允许作者或管理员执行。
- 策略库是内部共享研究空间；所有已认证用户可以读取策略和版本，代码当前不提供私有可见性。
- 普通用户不能伪造 `backtesting`、`validated` 等系统维护状态。
- 新策略必须从 `draft` 开始；进入待回测、回测中或已验证状态前，最新代码版本必须通过结构校验。
- 废弃策略只读；回测中的策略不能修改代码版本或关联标的。
- 已被回测引用的版本不能删除；已有回测历史的策略不能删除，避免级联清除研究证据。
- API 限制 JSON 请求体大小、文本字段长度，并对列表和版本详情设置上限。
- 版本列表只返回元数据，完整代码通过单版本接口按需加载，避免历史版本累积造成大响应。
- API 不向客户端返回 SQLite 或未知异常原文，详细异常只写入服务端日志。
- 静态校验拒绝文件、进程、网络、反射和动态执行相关的高风险导入/调用。

## 执行器前置条件

静态校验不是 Python 沙箱。未来接入 RQAlpha runner 时，必须在隔离进程或容器中执行，并使用最小权限、无宿主文件写权限、受限网络和资源配额。执行器只能运行 `validation_status=valid` 的代码版本，并且要记录版本哈希。

## 验证

```powershell
python scripts\check_strategy_security.py
```

该检查覆盖越权、状态伪造、畸形输入、危险代码、版本按需加载、重复版本名、废弃只读和回测历史删除保护。
